Python

Common uses: Automation, scripting, web apps, data science

def greet(name):
    return f"Hello, {name}!"

user_name = input("Enter your name: ")
print(greet(user_name))

JavaScript

Common uses: Front-end, back-end, interactivity

function greet() {
  const name = document.getElementById("nameInput").value;
  document.getElementById("output").textContent =
    "Hello, " + name + "!";
}
